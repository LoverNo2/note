代码块样式方案对比

同一段代码（含中文注释与中英混排）在 5 种代码块样式下的效果。当前代码块样式放在最前面作为对照。

当前样式对照

浅灰底 + 1px 边框 + 8px 圆角：中规中矩，但与页面整体的新拟态（柔和光影）语言不一致。

// Main::iteration —— 每帧执行的核心函数

    uint64_t ticks = OS::get_singleton()->get_ticks_usec();
    // 计算帧间隔（毫秒）
    double delta = (ticks - last_ticks) / 1000000.0;
    if (main_loop) {
        main_loop->iteration(delta);   // 进入主循环
    }
    return exit;
}
方案 A · 内凹卡面推荐

去掉边框，用内侧柔和阴影把代码“压”进纸面，13px 圆角。与工具栏、目录树同一套新拟态语言，整体最统一。

方案 B · 左侧强调条

极浅底色 + 左侧 3px 蓝色竖条，右侧大圆角。现代技术文档常见做法，视线容易定位代码边界，主次分明。

方案 C · 深色终端

深色底 + 浅色等宽字，代码最醒目、可读性最好。缺点是白纸页面上一块深色偏重，打印时也会很费墨。

方案 D · 细线稿最克制

透明底 + 1px 细边框，几乎不加装饰。正文与代码区隔清晰，打印友好、几乎不改变纸面观感。

说明：以上只改外观（背景 / 边框 / 圆角 / 阴影），代码块的排版（Menlo 13px、行高 1.7、换行规则）保持一致。
另外可选项：A 加一条 2px 的强调色顶线；B 的竖条换成中性灰；C 可只在屏幕上深色、打印时自动转浅色。
