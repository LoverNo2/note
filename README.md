# 笔记本 · Notebook

一个**冷调极简**（Notion / Linear 风格）的本地笔记本。Vue 3 + TypeScript + Vite 构建，
不依赖任何大型 UI 库与后端服务。

## ✨ 功能

- 📝 **笔记增删改**：左侧列表 + 右侧编辑区，切换即时生效
- 🎛 **预设样式工具条**：顶部一键切换 正文 / 一级/二级/三级标题、引用、代码块、分割线，
  无序 / 有序列表（`Tab` 缩进、`Shift+Tab` 退级），行内强调：粗体 / 斜体 / 删除线 / 行内代码
- ↩️ **所见即所得块式编辑**：自研 contenteditable 引擎，回车自动续列表、标题回车转正文、空项回车退出列表/引用
- 💾 **自动保存**：输入后 500ms 防抖写入浏览器 `localStorage`，页面刷新 / 关闭不丢数据
- 📄 **保存到本地文件**：顶栏「保存」或 `⌘S` / `Ctrl+S`——首次用系统对话框选择位置并授权，
  之后每次保存**原地覆盖**同一文件，不再反复弹“另存为”（Chrome / Edge）
- 📥📤 **备份与恢复**：一键导出 JSON 副本；支持从备份导入，按 id 合并去重
- 🎨 **冷调极简视觉**：浅灰侧栏、白底编辑、克制蓝强调色、细边框、轻盈滚动条
- ⌨️ **快捷键**：`⌘N` / `Ctrl+N` 新建；`⌘S` / `Ctrl+S` 保存到文件；`⌘Z` / `Ctrl+Z` 撤销；`⇧⌘Z` / `Ctrl+Y` 重做
- 🧱 技术栈：`Vue 3`（Composition API）· `TypeScript` · `Vite`，自研轻量组件，无多余依赖

## 🚀 快速开始

> 需要 Node.js **18+**（含 npm）。

```bash
npm install      # 安装依赖
npm run dev      # 启动开发服务器（默认 http://localhost:5173，自动打开浏览器）
```

生产构建与预览：

```bash
npm run build    # 类型检查 + 打包到 dist/
npm run preview  # 预览构建产物
npm test         # 编辑器引擎与 HTML 兼容层的冒烟测试（jsdom）
```

## 🗂 数据说明

- 数据保存在浏览器 **localStorage**（键：`notebook.notes.v1`），不经过任何服务器。
- 正文以**规范化 HTML** 存储（标题/引用/代码块等块结构与行内强调），旧版本的纯文本笔记
  在首次打开时会自动迁移为段落，无需手动处理。
- **保存到本地文件**（Chrome / Edge）：顶栏「保存到文件」或 `⌘S` / `Ctrl+S`。
  首次会弹出系统对话框让你选择保存位置并授权；之后按保存会直接**覆盖写入该文件**，不再弹窗。
  已授权的文件句柄存放在 IndexedDB 中，刷新页面后仍能原地保存。
  文件被移动 / 删除后首次保存会提示重新选择位置。
  Safari / Firefox 不支持静默覆盖写，会自动降级为每次直接下载一份备份。
- 侧栏「导出」始终提供一次性的 JSON 副本下载；建议定期导出一份或多份历史备份。
- 备份文件格式带 `app: "notebook"` 标识与 `version` 字段，导入时会做校验。

## 🧩 自研编辑器边界（首版）

自研块编辑器在不引入任何依赖的前提下，对以下场景做了简化处理：

- 撤销按输入停顿（约 500ms）合并一步，结构操作（切样式/列表等）各记一步
- 光标在块首的 `Backspace` 跨块合并依赖浏览器默认行为
- 粘贴统一转纯文本并按行拆段，富文本格式不会保留
- 标题内回车 → 后续内容转为正文段落；引用内回车 → 后续内容退出引用
- 行内强调（粗/斜/删/行内代码）需先选中文字再点击按钮
